## Features

- Basic arithmetic operations: addition, subtraction, multiplication, division
- Percentage calculation
- Clear and clear-all functions
- Cross-platform GUI (Windows, macOS)
- Responsive window sizing based on OS

## Installation

1. Clone the repository:# SimplePythonCalculator
A Simple Calculator Application In Python

```commandline
git clone https://github.com/yourusername/SimplePythonCalculator.git
cd SimplePythonCalculator
```

2. Install dependencies using UV:

```commandline
uv pip install build uv run -m build
```

## Usage

Run the calculator application:

```commandline
uv run python SimplePythonCalculator/Calculator.py
```

## Platform Support

- **Windows:** Default window size is 100x100.
- **macOS:** Window size is adjusted to 260x200 for better UI scaling.
